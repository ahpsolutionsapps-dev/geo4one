## Arquitectura

- Utilizar Clean Architecture.
- Organizar el código por features.
- Cada feature debe respetar separación de responsabilidades.
- Las reglas específicas de cada tecnología se encuentran en
  `.ai/rules/`.

Antes de crear una nueva feature:

1. Revisar features existentes.
2. Identificar componentes reutilizables.
3. Mantener separación de responsabilidades.
4. Evitar dependencias entre capas que violen la arquitectura.
5. No crear una estructura diferente sin justificación.
